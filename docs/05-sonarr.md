# 5. Sonarr — сериалы

Откройте `http://localhost:8989`. В **Settings → Media Management** добавьте корневую папку `/data/media/tv`. Настройте профиль качества, обработку сезонов и импорт завершённых загрузок.

В **Settings → Download Clients** добавьте qBittorrent: хост `qbittorrent`, порт `8080`, ваши учётные данные, категория `tv`. Проверьте соединение через **Test**. Путь загрузок категории — `/data/torrents/tv`; корневая папка библиотеки — `/data/media/tv`. Оба пути доступны в контейнере Sonarr через общий mount `/data`.

Подключите индексаторы через [Prowlarr](03-prowlarr.md). Если импорт не идёт, проверьте категорию, права файлов и путь, который qBittorrent возвращает Sonarr. Правила предпочтения русской озвучки описаны [отдельно](08-russian-audio.md).
