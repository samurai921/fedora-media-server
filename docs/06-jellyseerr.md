# 6. Jellyseerr — запросы

Откройте `http://localhost:5055`. На первом запуске свяжите Jellyseerr с Jellyfin: адрес внутри Compose `http://jellyfin:8096`, учётные данные вводите в веб-интерфейсе. Настройте доступ пользователей и разрешения запросов.

Добавьте сервер Radarr с адресом `http://radarr:7878` и сервер Sonarr с адресом `http://sonarr:8989`. API-ключи возьмите из настроек соответствующих приложений и вводите только в интерфейсе Jellyseerr. Выберите корневые папки `/data/media/movies` и `/data/media/tv` из предложенных приложениями, настройте профили качества и сохраните настройки.

Для пользователей в браузере на сервере адрес — `http://localhost:5055`; с другого устройства в LAN — `http://<LAN-IP-сервера>:5055`, если разрешён доступ через firewall. `localhost` в настройках Jellyseerr не подходит для связи с другими контейнерами. Доступ через LAN или подготовленный HTTPS-домен требует аутентификации.

## Доступ через интернет

Подготовлен адрес **https://requests.mediadima.ru**. Он станет доступен после настройки DNS, выделенного медиатуннеля и Caddy: [инструкция по доменам](13-service-domains.md). Вход в приложение обязателен. Внутренние адреса Docker остаются прежними.
