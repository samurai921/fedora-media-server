# 4. Radarr — фильмы

Откройте `http://localhost:7878`. На первом запуске задайте вход и профиль качества по своим требованиям. В **Settings → Media Management** добавьте корневую папку `/data/media/movies`. Включите переименование и импорт завершённых загрузок, если это соответствует вашей библиотеке.

В **Settings → Download Clients** добавьте qBittorrent: хост `qbittorrent`, порт `8080`, ваши учётные данные, категория `movies`. Нажмите **Test**. Пути загрузок остаются внутри общего `/data`: `/data/torrents/movies`. Не добавляйте Remote Path Mapping, когда все сервисы видят одни и те же пути.

Radarr должен иметь право записи в `/data/media/movies` и чтения из `/data/torrents/movies`. Для экономии места жёсткие ссылки возможны, когда загрузки и библиотека лежат на одном файловом разделе; общий mount `/data` это допускает. Удаление исходного файла из клиента после импорта может влиять на раздачу, поэтому проверьте правила хранения перед автоматическим удалением.

Индексаторы удобнее подключать через [Prowlarr](03-prowlarr.md). Для предпочтений по русскому звуку см. [отдельную главу](08-russian-audio.md).
