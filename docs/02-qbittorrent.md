# 2. qBittorrent

Откройте `http://localhost:8080`. В контейнере других сервисов используйте `qbittorrent:8080`. Первый временный пароль пользователя `admin` смотрите в `docker compose logs qbittorrent`; после входа сразу смените его в настройках Web UI. Пароль не записывайте в репозиторий.

В настройках загрузок задайте каталог по умолчанию `/data/torrents`. Создайте категории `movies` и `tv` с путями `/data/torrents/movies` и `/data/torrents/tv`. Включите сохранение по категориям и проверьте, что завершённые загрузки лежат в этих каталогах. Не указывайте путь хоста `./data/...` в интерфейсе контейнера.

В настройках соединения проверьте входящий порт `6881`. Compose публикует `6881/tcp` и `6881/udp`; переменная `TORRENTING_PORT` задаёт тот же порт внутри образа. `8080` — только Web UI.

Radarr и Sonarr подключаются к клиенту по хосту `qbittorrent`, порту `8080`, с вашим логином и паролем. Категории для фильмов и сериалов должны различаться. Используйте загрузки только для контента, который можете получать и распространять законно.

См. [документацию LinuxServer](https://docs.linuxserver.io/images/docker-qbittorrent/).
