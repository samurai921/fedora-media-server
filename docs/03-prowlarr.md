# 3. Prowlarr

Откройте `http://localhost:9696`. Добавляйте только легитимные источники, к которым у вас есть право доступа. Следуйте условиям этих источников. Если источник требует личные данные доступа, вводите их только в интерфейсе Prowlarr; не помещайте пароли, API-ключи и cookies в репозиторий.

В **Settings → Apps** добавьте Radarr и Sonarr:

| Приложение | URL внутри Compose | Где взять API-ключ |
| --- | --- | --- |
| Radarr | `http://radarr:7878` | Settings → General в Radarr |
| Sonarr | `http://sonarr:8989` | Settings → General в Sonarr |

Сохраните каждое приложение и запустите **Test**. При необходимости настройте синхронизацию индексаторов с приложениями. Адрес `localhost` здесь неверен: для Prowlarr он означает контейнер Prowlarr. При добавлении источника проверьте его доступность штатной кнопкой Test.

FlareSolverr в Compose существует как необязательный профиль и по умолчанию выключен. Для разрешённой вами инфраструктуры его можно запустить командой `docker compose --profile flaresolverr up -d`; сетевой адрес `http://flaresolverr:8191`. Инструкции по обходу защит сторонних сайтов здесь не приводятся. Если источник недоступен, проверьте его правила и официальный способ доступа.
